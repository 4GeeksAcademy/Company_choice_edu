# Plan de implementación

1. Explorar el monorepo y documentar discrepancias y convenciones.
2. Crear reglas del agente y memoria de producto, stack y estado.
3. Documentar la taxonomía y los contratos compartidos.
4. Implementar la API de incidencias y su historial auditable.
5. Implementar el backoffice con alta, edición, filtros, detalle y vista general.
6. Ejecutar pruebas, revisar el checklist y documentar la ejecución.

Cada fase se confirma en un commit separado. La persistencia, autenticación y despliegue quedan fuera de este MVP salvo que el contexto las requiera.
